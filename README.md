# Tetris Animation

A smooth, lightweight Tetris-style animation built using HTML, CSS and a small amount of JavaScript.

This repository contains a small demo that animates Tetris pieces and the game board using CSS animations and transitions — perfect for learning CSS layout, transforms and animation timing.

---

## Demo

![Tetris Animation Screenshot](./Screenshot%202024-08-23%20085758.png)

You can run the demo locally by opening `index.html` in your browser.

---

## Features

- Purely CSS-driven grid layout and piece styling.
- Smooth piece animations using CSS keyframes and transforms.
- Minimal JavaScript to initialize or tweak animation timing.
- Small, easy-to-read codebase (great for learning and modification).

---

## Files

- `index.html` — Demo page and markup for the Tetris board and pieces.
- `style.css` — Styling and animations (most of the project).
- `Screenshot 2024-08-23 085758.png` — Demo screenshot used in this README.

---

## How it works (high level)

1. The board is created using HTML elements laid out as a grid.
2. Each Tetris piece is represented by a group of elements styled with CSS.
3. CSS keyframe animations and transforms move and rotate pieces to create the Tetris effect.
4. JavaScript (if present) controls animation timing or dynamic class toggles.

---

## Usage

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Tetris-Animation.git

2. Open `index.html` in your web browser.

No build step or dependencies required.
